# CampusOpt Frontend Demo

Demo này mô phỏng giao diện trực quan quản lý phòng học theo chủ đề:
**CampusOpt — Hệ thống phân tích và tối ưu sử dụng tài nguyên phòng học trong khuôn viên đại học**.

## Công nghệ demo

- React + TypeScript + Vite
- MapLibre GL JS (bản đồ nền)
- deck.gl (vẽ lớp phòng học và nhãn tương tác)
- Turf.js (tính centroid/diện tích phòng mẫu)
- Konva (mini floor plan)

## Chạy local

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
```
